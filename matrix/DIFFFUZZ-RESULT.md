# Differential fuzzer result

`tools/difffuzz` adds argument fuzzing over existing matrix/test/corpus subjects, deterministic syntactic mutations, exact graph/type/bit/exception/effect comparison, bounded shrinking and checked portable replay, immediate shared-corpus publication, and a ten-minute below-normal mode with one to four workers. It changes no compiler product source. The README describes use before the one independent implementation review and before each commit.

The argument-only ten-minute run against accepted trunk **386b6e99ec8ab7cb25193cd2c1b322e971fa9603** used seed 61001 and 3 workers alongside the serial suite. It executed744 of 1,781 discovered subjects (inventory1,016 matrix / 627 test / 138 corpus); this is a sampled run, not complete domain coverage. There were **26 case/engine counterexamples: 12 in lift.py and 14 in heap.py**, all with checked portable reduced recipes and immediate wave17-prefixed corpus entries. These counts include repeated root causes; they are not 26 distinct compiler bugs.

The run checked 4,494 native input trials and 34,302 public Python fallback trials, with 338 construction declines. Separate unchecked outcomes: 4,583 unsupported oracle trials,8,525 resource-filtered trials,463 unavailable extracted fixtures and 5 timeouts. There were **0 worker errors**. Raw per-case outcomes and command: `matrix/difffuzz-trunk-a-v2/results.jsonl`, `report.json`. The earlier seed 1729 development run found 49 counterexamples (heap 30 / lift 19), with 5 tool errors corrected during development; do not add the two run counts as unique bugs.

Examples are borrowed tuple copies in scalar lift returns, string constant/input copies in heap returns, repeated tuple alias loss, and returned instance dictionary order. Seed1731's heap string constant replay still reproduces with the final oracle against the same accepted trunk. Owner reports and all 75 reduced samples are in the shared `provenance-cases` folder and append-only REQUESTS.md; the module split above identifies the implementation path, not a new assignment of protected load/write-back work.

Own fail-first tests cover exact type, NaN payload/-0.0, nonnumeric selected identity, aliases/cycles, argument/global mutation, stdout/events, exception chains, cold/warm calls and fallbacks, deterministic domains, shrinking, recipes and inventory/mutation. The sole independent implementation review found six concrete oracle/replay defects; each has an executable regression and was fixed without re-review. Global creation no longer contaminates later replays; exact class identities are distinct; unsupported reachable class/callable/module arguments decline; instance-dictionary aliases survive copies; yields before exceptions remain observed; nonfinite frozenset recipes use bit-exact emitters. Final focused command: `python -m pytest tests/test_difffuzz.py -q` (**29 passed**). The single full-suite run over the accepted parent plus the tool finished with 2,432 passed, 2 xfailed and 131 subtests, plus 18 missing-development-tool failures in the temporary checkout. Restoring those accepted parent files cleared all 18; the final focused run of test_difffuzz.py and test_dev_inspect.py passes 47 tests (29 tool + 18 restored checks). No second full-suite run was made.

Known unchecked areas are one line each in `KNOWN-GAPS.md`. No speed or new native-coverage claim is made for this developer tool. Unicode remains unaccepted until the known source-callback defect is fixed; the next order is Unicode, S57 exact original-context binding, then object calls.
