# Character-loop ceiling under S38.3 (unmeasured)

The owned source audit finds no dedicated long character scanner among the40 benchmark-owned files: meteor's c loops traverse coordinate collections; hexiom.read_file parses two-character grid cells while allocating a graph, rather than scanning a long string. This is a statement about the retained source/workloads, not inferred support for arbitrary dynamic loop receivers. Use the authorized stdlib tokenizer substitute: installed shlex.shlex.read_token, reached through workload.token(text), which constructs one private default-POSIX lexer and reads a complete token. All quote, escape, comment, Unicode, error and EOF branches reachable from that constructor are included. Non-POSIX, punctuation-mode and externally supplied/stateful lexer instances are not inputs to this wrapper.

Three complete-call routes: CPython; boxed CPython API loop through the existing managed Numba/AOT bridge; borrowed pinned Unicode kind/data/length through the same bridge. Boxed retains StringIO.read and repeated Unicode concatenation. Borrowed scalar-replaces the private lexer/StringIO state, reads the original pinned text, uses a native UCS4 temporary and constructs the Python result once. The bound therefore includes eliminating private state/stream and repeated result allocations, not solely the cost of character access. Result storage is canonicalized by PyUnicode_FromKindAndData; cached-character/input alias behavior must be tested, not assumed.

Trusted installed stdlib setup (source-hashed); no active sys.monitoring global/relevant local events or importtime instrumentation, and nominal tracing/profiling off (active trace/profile delegates); exact str entry; unchanged wrapper, constructor, read_token and punctuation getter codes/defaults; exact ordinary lexer metaclass/slots/bases/class dictionary; string-keyed globals/builtins, required binding identities and no registered GC callbacks. A failed guard delegates to the original wrapper before execution. The lexer is proven private by its unchanged constructor/body and wrapper: token state, pushback, lineno and consumed stream state cannot escape. The borrowed route omits these private writes but preserves complete result/exception behavior. Error message objects come from the original code constants. Exact string/stream operations have no user callbacks. Ambient cyclic-finalizer scheduling, allocation-failure injection, signals, free-threading and subinterpreters are outside this diagnostic proof and are not product claims.

Behavior before timing: full default-mode grammar witnesses, deterministic randomized Unicode/quotes/comments/escapes, long1/2/4-byte operands, original-argument/cached-character identities, success/error refcounts, binding/code/class/defaults/GC guard misses, ordinary JIT/AOT and fresh AOT without Numba. Independent review before accepting the bound. One three-pair locked timing cohort on20,127,4096 and65536-character operands; no product source edits or scanner implementation before the decision.

The deferred collections import is part of constructor semantics. Guards must prove the actual cached path: original builtin importer, exact cached collections module, present deque and __path__, stable non-initializing spec without descriptors/truth callbacks, and the reachable _handle_fromlist function/bindings. AOT callable references are retained in the module environment at initialization, not unpickled on each call. Any non-inert context delegates before constructor effects. The finite-path proof uses CPython3.14.4 Python/import.c (https://github.com/python/cpython/blob/v3.14.4/Python/import.c) and installed Lib/importlib/_bootstrap.py; it is diagnostic and not a generic import optimizer.
