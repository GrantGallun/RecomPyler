# S34 diagnostic design (final revision)

No product backend change. Three held-out complete bodies use direct CPython extension entries. Exact profiled domains use specific APIs and arithmetic; failed guards call the original before body effects. The final implementation and all specializations, invalidation guards, ownership gates and limits are described in COMBINED-BOUND.md. Earlier generic C fallback routes were rejected after executed finalizer-order witnesses; they are not accepted code. Type tags are CPython3.14 unstable API and public dictionary watchers consume one process-lifetime slot. Registered GC callbacks select original execution. The prototype proves the executed gates and specific ceilings; a production emitter still needs a full effect/deoptimization/ABI design.
