# Shared provenance layer (S47, S49)

The neutral module is src/recompyler/provenance.py. _text_owners.py becomes the first adapter, retaining only text eligibility, typed result policy and materialization. The shared module has no Numba dependency and holds no application objects: stable source coordinates, primitive code/dependency identities, constant-index paths and origin descriptors only. A summary is compile-scoped; dependency IDs are guards, never durable-AOT object recipes.

Abstract Value contains a finite set of Origin possibilities plus optional structural children. Origin kinds are argument, constant, global, attribute, element, allocation, operation, singleton and unknown. An operation is NOT certified fresh: overloaded operators may select an existing object. A typed consumer may ignore owner identity only for exact builtin int/float/complex (S49), retaining exact value/type checks. bool/None and all other objects keep exact identity. Numeric identity observations are refused unless kinds prove a nonnumber or singleton comparison. Unknown calls may observe every actual and invalidate mutable-location facts; no generic pure-call assumption is made.

Statements record before/after environments and expression facts using source IDs. Branch joins retain unions, not whichever branch was visited last. Loops widen every body/target store before analyzing body/else, so an allocation site inside a loop is not a dynamic instance certificate; break/continue terminate that path and break exits join the else continuation. Unsupported CFG forms (try/finally, with, comprehensions, closures/nonlocal, generators) record unknown/decline, never a partial whole-function certificate. Return/store/yield/unknown-call roots recursively escape their children. Aliasing between external arguments/paths is conservative; separate allocation sites outside loops are distinct, but a shared assignment is one origin. A source-only fact never certifies physical-cell rooting, callback-free layout or journal retirement.

Bind dedented original source to original bytecode (including folded constants) before analysis. Resolve original constants using LOAD_CONST index paths, with no value-equality owner inference. Dependency guards cover original code/default/closure/global identities and inert namespace shapes; the summary retains IDs rather than graph references. Source mismatch or missing instruction positions returns unknown. Consumers still guard types/layout/effects before applying a proof.
