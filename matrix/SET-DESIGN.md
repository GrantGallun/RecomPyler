# Native non-escaping sets

The external future-mutation red witnesses invalidate native boxing even for the finite universe. Do not keep a table-order specialization or an unused escape proof in product. Admit scalar-only results over exact signed-int64 native sets (input copies and local sets), pure algebra/predicates, and guarded local mutators; no reflected input mutation, pop, iteration consumers or set-bearing result. Recursive Optional/tuple/list/record set detection is mandatory. No integer reference escapes, so neither canonical-singleton nor cache-range nor CPython table-version guards are needed. Big ints and bool/float/subclass elements decline before preparation; existing integer arithmetic guards continue to apply. Every native set allocation is private, and input sets are detached copies.

The sound escaping representation is a managed CPython set owner, distinct from Numba's working hash table. Borrowed read-only scalar operations may use a Numba Set; an escaping operation instead retains/materializes a CPython owner through managed-object intrinsics using exact set-specific APIs (copy/algebra/add/discard), preserving actual table state and selected identity. Local mutable state that can escape must stay on that owner representation from its first mutation, rather than reconstructing its final membership. Mixed native/managed phases require explicit effect/escape summaries and no replay after external effects. S38.4's two-of-three parity gate governs building this breadth; until that gate, these result forms remain cleanly declined with executable expected-fail coverage. This is the concrete representation design demanded by the measured counterexample, not a claim the missing analysis makes the subsystem impossible.

Earlier rejected native boxing experiments are retained in the ledger, receipts and independent review, not product design. S40 supersedes their finite-domain and tuple-escape approaches. The positive typed-use certificate rejects nested Set-bearing arguments and requires a directly typed Set receiver for each recognized helper. Unsupported set typing has a named decline, including indexed lowering of direct iteration. Ordered-source update and order-insensitive reducers beyond len remain named recognizer work; float sums remain declined.
