# Independent S31 prepared-AOT cache proof review

Static design review only. No workload, build, test, profile or timing was executed. Scope: current `src/recompyler/{heap,_region_seed,_origin,aot,lift}.py`, S31, and `wave14-capture/validation/s19-startup-design-notes.md`.

The architecture proposed by the cache author is viable: persist a primitive, post-settle execution descriptor, seal its canonical digest in an export of the native artifact, rebind current definitions, and reuse the existing runtime loader/guards. This is conditional design approval, not approval of an implementation that has not been written/reviewed.

## Required hit boundary

The hit lookup must precede `Region.program_for`'s `_make_program` and `_seed(args)`. `_Program.__init__` creates `_Function`, which parses source and computes flow; `_seed` calls `register` and constructor-layout inference. Skipping only `compile` leaves these analyses on the hit. Construct a runtime-only object without `_Program.__init__`, `_Function.__init__`, `register`, inference restore, settle, range/escape/scalar passes, or generated-source emission. Use ordinary `Region.load` to establish each call's actual contracts. A failed cache record goes to the original AOT-only regeneration path, with its exact export check, not a new JIT route.

## Constructive descriptor schema

Use canonical JSON primitives and explicit versions. The core must contain:

1. **Build and selection identities:** schema version; complete compiler/generator/runtime implementation hash; source file and executable code hashes for entry and dependencies; complete semantic plan/seed identity; target/numeric options; Python/extension/loader ABI; generated source and generated-source digest; exact digest-to-native-export relation and machine argument/result signature.
2. **Kinds and cells:** a closed kind grammar for the current primitive, optional, object, tuple, list/array, string, dict/set, ndarray and RNG types. Cells have integer IDs, kind and mutation flag; repeated IDs preserve sharing and recursive container topology. Persist no Python addresses or precomputed C plans.
3. **Class layout:** statically rebound class recipes, exact MRO and constructors, class attribute-name sets, ordered family fields and kinds, ordered concrete members (native tag numbers), family aliases, and canonical written-field pairs. Preserve ordering; JSON object sorting must not reorder fields or members.
4. **Entry and attribution:** entry parameter order and kinds, return kind/constant, sink/generator information if runtime needs it, and ordered function rows rebound to original functions for bailout function/line attribution. Scalar clones retain their original function recipe. Runtime does not require compiler call-graph/fixed-point state or analysis reports; report primitives may be carried for diagnostics only.
5. **Globals and flags:** ordered `(namespace recipe, key, kind)` entries; string-constant holder data; array-view and array-write flags, and every other runtime-consumed flag. Internal holders, closure-cell views and RNG holders require explicit safe recipes or must decline the prepared record.
6. **Guards and dependencies:** every guard in the final program, not just `_region_seed.dependencies`. Serialize code, lifetime, attr, own, item, builtin, const and kwdefaults guards with their exact expected identities/value encodings and absence conditions. Unknown guard/value/namespace recipe means prepared miss. Include all functions/classes referenced by layouts, functions, globals, guards, defaults and supported closures, then close over constructors, MRO bases and defining-class cells.

Actual execution consumers inspected: `_Loader` uses entry params/kinds, globals, shared kind contracts, `load_plan/c_kind/c_plan/c_ok`, and `array_views`; `_Unloader` uses return kinds, families/tags/layout, class fields, written pairs and mutated cells; `Region.attempt` uses `arrays_written`, ordered function attribution, `run`, `ahead_of_time` and `broken`. `constant_blocks` additionally depends on ordered globals and the string holder. Recreate `_load_plans`, `_c_kinds`, `_c_ok_cache`, `_c_plans`, `_c_write_plans` lazily from the sealed state after binding. Never reuse process-specific cached plans.

## Key and seal construction

Make the construction acyclic. A semantic plan projection excludes only explicitly derived cache payload/seal/artifact-location fields; it must retain picks, selection/budget/options, seed and export mapping. The core commits to that projection and its complete descriptor. Native module naming may derive from the core/bundle seal. The final binary hash is an outer binding and must be checked before import; it cannot recursively be inside the payload from which that same binary is built. Document final plan assembly ordering and the projection precisely. A plan edit must be a miss even when someone updates an unsealed JSON checksum.

The native metadata export must return the full canonical core/bundle SHA256 (for example, eight exact uint32-range integer words). Validate its exact output shape/type/range and equality before attaching the computational export. A descriptor checksum stored only in the same JSON is not sufficient: changing `written`, `entry.ret`, guards or array rollback flags while recomputing that checksum must still reject. Seal the association among each descriptor, digest, function identity, export name and machine signature, including multi-record bundle ordering.

Compiler identity must cover all generation and runtime-contract inputs, including `_facts`, flow/range/numeric policies, scalar/escape, seed/origin/prepared code, helper generators, vendored `_pycc`, and native loader source/binary/contracts version. Hashing all packaged source files plus required binary identities is a conservative simpler implementation. ABI identity includes Python implementation/version/cache tag/SOABI, platform/architecture/pointer width/endian, extension suffix, NumPy/Numba/llvmlite/compiler versions and actual compilation target/options. Obtain version metadata without importing Numba on a hit. A source digest that currently hashes only five generator files is not this complete key.

## Static rebinding and dependency proof

Resolve only exact functions, plain classes and plain modules through known dictionaries; never import arbitrary payload modules, execute payload source, call `eval`, arbitrary `getattr`, `repr`, user equality/hash, descriptors or metaclass hooks. Verify intermediate and terminal exact types. Unwrapping must follow the same trusted original-function convention as generation and also preserve any guards on wrapper bindings.

For every function, validate complete executable code (including nested code constants where supported), immutable defaults and keyword defaults, exact closure schema and cell values. Supporting only the existing `__class__` cell is safe if other closures take the old path. Do not infer dependency closure merely from `co_names`: the final compiler guard inventory plus all emitted/referenced functions/classes and global recipes is the authoritative recorded dependency set. Verify methods by static MRO lookup and include earlier-class absence/shadow assumptions. Validate builtins and namespace overrides, copied constants and mutable-global binding identities, then retain equivalent live guards.

Use bit-exact primitive encodings: float bytes or equivalent distinguish signed zero and NaN payloads; bytes are encoded as bytes, tuples are tagged recursively, bool is not accepted as an integer ID. Unsupported literals decline the prepared record. Existing repr-based origin/default fingerprints alone do not establish this stronger exactness property.

For each class, validate plain type/metaclass, full MRO, constructor binding/code/defaults, slots/member descriptor ownership and layout (`__basicsize__`, `__itemsize__`, dictionary/weakref offsets where applicable), and `_object_problem` eligibility. Keep finalizer/custom-allocation lifetime guards and MRO/method guards active after binding. Do not retain live instance graphs, weakrefs, loader objects, temporary candidate loads or object addresses in a persistent descriptor cache. The normal per-call loader owns its usual transient pins. Preserve all alias, mutability, overflow, recursion, array shape/stride/writeability, result conversion, rollback and writeback checks.

## Fail-first test matrix

- Valid fresh-process hit: replace `_make_program`, `_seed`, inference restore, `_Program.compile`, settle, range/escape/scalar analyses and source generation with raising sentinels; a real native completion must still occur, with identical result/stdio/stderr/mutation/identity and no Numba/LLVM import. An on/off counter check must prove the computational export actually ran.
- Independently change source bytes only; live bytecode/constants only; helper code/default/keyword default; supported closure cell; method replacement or inherited shadow; constructor; class MRO/slots/attribute hooks/finalizer/allocation; global binding/value or builtin override; seed; semantic plan field; compiler/helper source; target/numeric option; ABI version; binary bytes; export name/signature. Each must decline or follow the unchanged exact AOT-only regeneration route before native entry.
- Tamper every execution-critical descriptor family: entry argument/return/constant, guard deletion/change, ordered fields or member tags, aliases, cell sharing/mutation, written pairs, globals order/string holders, array flags, attribution order, digest/export association. Recompute all JSON-side hashes; the native seal must still reject. Cross-swap two individually valid record/export pairs and reject.
- Malformed/unrecognized payloads: duplicate names/keys, out-of-range references, wrong exact types, invalid kind tags, illegal alias cycles, inconsistent family membership, excessive nesting/size, invalid native seal return shape/range. Legal recursive cells remain supported. Miss handling must not catch arbitrary application exceptions or turn malformed state into partial attachment.
- Mutation after successful bind: replace code/defaults/kwdefaults contents, class cell, method, MRO, lifetime property, global or builtin binding. Per-call guard invalidation must happen before native execution and retain original fallback behavior.
- Runtime parity: aliased/repeated/cyclic objects and containers, mutations then bailout, ndarray overlapping views and retry rollback, integer boundaries/mixed numerics, recursion limit and bailout source mapping, fresh object/weakref lifetime, generator/coroutine consumers where eligible. Failed records and failed loads leave no new persistent pins or partial program cache entry.
- Legacy compatibility: missing prepared section, unsupported closure/holder/guard, stale record and legacy-only plan retain old AOT deployment opportunity, exact export validation, ordinary gate/budget and native/fallback counters. No workload-name special cases or reordered broad-first seeds.

Before implementation acceptance, make the key projection, schema closure, static recipe grammar, native seal binding and fallback attachment points concrete in code and test each. No claim that an absent proof closes coverage is justified; unsupported prepared metadata must preserve the original path.
