# Direct-store preparation (not activated)

Status: design input for Step3 after accepted direct reads and achieved/bound investigation. This is not an implementation or an acceptance checkpoint.

The transaction shares Step2's header-derived layout, canonical physical locations, input ownership map, numeric provenance and raw adapter. Numeric field/list stores are eligible only with a transitive no-observer/no-topology certificate. Fallback is selected before publication for unsupported effects. Input arrays require the same rollback coverage or a computed whole-region arena decision.

One C execution envelope freshly walks/pins the live graph, validates the compiled entry and runtime capability, executes native work holding the GIL, and commits or restores before returning to Python. No Python call boundary may occur while speculative stores exist. Decline free-threaded mutable graphs, Python callbacks, GIL release, unsupported native helpers, dictionary watchers and custom descriptors. Strong pins are acquired only inside the final atomic interval, never across a preparation callback that might add a finalizer and detach an owner.

The typed journal uses physical owner/storage-slot identity, shared across every alias. Each entry owns the old exact numeric reference and typed metadata before publication; each new numeric reference is completely ready before the target pointer changes. Failure restores in reverse order, with every replaced reference retained until restoration completes. Repeated writes either log every prior value (reverse replay) or use a proven first-write table; the implementation must state which. Capacity/overflow/allocation failure checks precede the relevant store. No Python replay starts until all live locations and arrays are restored.

Exact numeric boxes have no finalizers/weakrefs and do not trigger cyclic GC, but allocation itself needs a positive callback-free allocator capability. A custom Python allocator hook cannot be assumed inert. Build an installed-runtime capability check or preallocation protocol with a valid observer proof; do not close the journal as missing that analysis. Raw malloc-backed journal/provenance arrays must also have an audited no-Python-callback contract. Native exception buffers/NRT cleanup are discharged before leaving the envelope, with raw status propagated until rollback is complete.

For ordinary records distinguish inline values, materialized split/combined dictionaries, and exact member descriptors. Use installed header fields, never copied offsets. Publish only existing numeric locations: key sets, insertion order, owner topology and list storage stay unchanged. Reject watched dictionaries and preserve dictionary/GC invariants. Mixed payload/tag describes the same one published box. Never suppress a distinct-but-equal numeric replacement; existing and dynamically produced tokens preserve Python identity and sharing.

Native overflow, bounds, native exception, allocation failure, recursion exhaustion and arena-growth exits all pass through one restoration routine. A native exception cannot reconstruct a Python exception before restoration. Guard failure during preparation never uses stale input loading. Result conversion that might allocate a tracked graph is selected/materialized safely before live stores, or causes a pre-entry arena decision. Existing/numeric/None results can finish without a tracked observer while the journal is active. Release unrelated pins before any later observable result allocation.

Fail-first behaviors: partial writes followed independently by each failure exit; mixed float->int and int64 limits; repeated/aliased writes through record/list paths; current returned box identity and distinct equal replacement; dictionary/descriptor/class changes at final C boundary; watchers, finalizers and weakrefs; signals/profile callbacks at envelope entry; unsupported native cleanup; free-threaded rejection. Independent guard/journal review precedes all timing. Whole-call, trivial-call, actual deployment and achieved/bound results decide acceptance.
