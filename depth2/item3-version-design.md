Each candidate has explicit MIXED field-load/scalar-input tag metadata from the generator. F4 answers hold under one function-entry guard; F5 checks all relevant field writes/capture effects and constructor calls. The existing checked body remains the guard-miss body, with unchanged status/error order.

A float version replaces only the guarded input tag reads/parameters with constant False. Existing arithmetic flag propagation then folds to float, and the integer exactness and integer-zero canonicalization branches disappear only where those flags prove false. No observed identity is used as a nonalias proof.
