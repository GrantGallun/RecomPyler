# S30 current-source raytrace ladder

Use the final frozen accepted source, selected exact AOT module and original default scene. All counterfactuals are diagnostic only on the valid default input with adequate arena capacity; no product rewrite is shipped. Retain strict generic target, original math and traversal, no false F/I noalias, no fastmath. One shared-lock hold covers the separate semantic counters, builds/smokes and three fresh alternating observations per stage with C and both hand native/full references.

Stages: whole current product; identical native body with scene construction/load/guards/writeback outside timer; scene/light list preallocation by actual validated cardinality; fused intersection storage that removes every individual tuple bump but retains every payload/handle store; whole-graph fixedFLOAT construction/storage and three-payload scalar ABI; streaming ordered firstIntersection minimum that removes all intermediate tuple payload/list materialization as a group; matched LLVM reoptimization replay; constant-selector SCC splitting plus selective colourAt-edge inlining; existing strict hand core and full hand setup; C. A standalone current-to-fixedFLOAT comparison exposes order interaction. Conditional signed differences and unresolved effects are retained, not independent additive cost shares.

The stream diagnostic retains object/intersection evaluation order, optional-presence test, strict t>-1e-5 selection and first-on-equal nearest tie. Fresh invocation locals preserve recursive call state. It is not a generic effect/failure/identity proof; sound future emission requires virtual-container F2, callee/evaluation F5 and failure-order certificates. Exact AST/source-shape assertions prevent partial accidental matches. Selector cloning preserves full ABI, rewrites only literal selector calls, requires verified optimized removal of the colourAt edge and a self-recursive rayColour edge remaining, and has an unmodified replay control. This measures call/dispatch/ABI propagation together, not pure call latency.

Before timing, actual allocation counters use instrument-off and instrument-on independent inputs with identical full pixels/highwater; report what fraction of tuple/list allocation was removed and what stores remain. Then all native variants verify complete original pixel SHA, clean status, exact five direct native calls and no Numba/JIT. Whole-product AOT maps match exact selected counts with no fallback/missing/batches, and hand variants verify full pixels. Native setup is outside its timer and typed hand full setup is inside, so the restored-setup counterstep is reported. Source and binary hashes identify actual artifacts; failed runs are excluded from every aggregate.

No historical ray timings enter this ladder. The difference still left after these partial/grouped stages is explicitly unclosed representation/control/remaining recursive ABI work, not irreducible pipeline overhead. Add/update catalogue candidates and current bounds only after observed gates/results. Independent source review is in ray-current-review.md; final timing is the separate CHECKPOINT51 BOUND.
